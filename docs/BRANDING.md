# Brand and artwork

**Project-facing name:** AI Control Center.

**Repository name:** ASUS-AI-Control-Center (historical; renaming is a separate decision).

The current application window, some launchers, Python paths and documentation still use "ASUS AI Control Center". This documentation change does not rename the software or imply affiliation with ASUS.

## Visual identity

- Primary appearance: Midnight Titanium / Frosted Titanium.
- Accent: blue/cyan.
- Mascot inspiration: Brazilian jewel beetle, *Euchroma gigantea*.
- Positioning: a local-first AI workstation control utility.
- Tagline: **Your local AI, under control.**

The README uses the bundled vector banner in <code>docs/assets/ai-control-center-banner.svg</code>. This is a lightweight, source-controlled adaptation of the beetle motif designed for GitHub rendering.

The separately generated high-detail illustrated marketing banner is a distinct image asset. It should be added as a binary file after reviewing the artwork for branding, third-party marks and claims. Do not state an MIT license in the published banner unless the repository's actual license has been selected and a matching LICENSE file is present.

## Intended uses

- GitHub repository README hero
- Project documentation and announcements
- Desktop shortcut icon (separate asset integration and regression test)
- Sidebar and window branding (separate frontend change)

Do not replace existing application icons automatically as part of a documentation-only update.

## Release checklist

- Verify the chosen distribution license and add its actual LICENSE file.
- Complete outstanding remote/security audit before changing repository visibility.
- Keep all local credentials and launch URLs out of artwork and screenshots.
- Ensure all compatibility and trademark notices remain accurate.
