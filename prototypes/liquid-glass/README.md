# Isolated material study

This is synthetic, non-operational content. Open `index.html` after `npm ci`; use `?concept=a&theme=dark` (or `b`, `light`). Model details is an always-visible sample, not a functional modal. The production interface is untouched.

Concept A uses @dpawlikowski/liquid-glass 0.3.0 CSS and a static equivalent of its MIT-licensed SVG filter, with the duplicated scene limited to the instrument. The library duplicates a scene; it does not refract arbitrary live page content. Concept B uses CSS gradients, blur, edge highlights and shadows. Both have the same prototype content and palette. No automatic animation is used. Firefox and Chromium screenshots at 1440 × 960 are in evidence/. Current screenshots use the app's existing demo fixture, so content and layout differ from the prototype; they are contextual comparisons, not controlled image-difference inputs. The two concepts are controlled comparisons.

`npm ci` then `npx playwright install chromium firefox` provisions local test tooling. Run `node prototypes/liquid-glass/capture.mjs` and `node prototypes/liquid-glass/capture-current.mjs` for evidence. `npm run visual:existing` runs the existing Firefox fixture; set `AI_MANAGER_E2E_BROWSER=chromium` for Chromium. `npm run visual:prototype` runs computed-style checks and snapshot assertions. It deliberately fails until references are explicitly reviewed. After approval, create references with `APPROVE_PROTOTYPE_SNAPSHOTS=1 npm run visual:prototype -- --update-snapshots`, review the resulting files, and commit only the approved references. Never use that command to silently accept changes.

The optical result is brighter than B, but visible edge refraction is weak on this smooth background; the duplicate scene is not registered to real page content. B has a calmer hierarchy. Neither has been approved. No performance, contrast, mobile, high-DPI or accessibility certification is implied by these captures. GPU and idle CPU have not been measured. CSS blur and SVG filters entail compositing cost; the static filter avoids continuous animation but needs profiling on GX10. The package has no runtime dependencies, an optional React peer, and MIT license; `npm audit` found zero known vulnerabilities on 2026-11-04, not a security guarantee. Playwright and the library are pinned development dependencies.
